# Waffenträger E 110 — мод для World of Tanks Blitz

Немецкая ПТ-САУ X уровня с задним расположением рубки, собранная из файлов в
папке `tank2/` и оформленная по образцу остальных модов этого репозитория.

```
mods/germany_waffentrager_e110/
├── assets/tanks/            ← копируется в assets/tanks/ игры
│   ├── germany_waffentrager_e110.glb           модель (5,5 МБ)
│   ├── germany_waffentrager_e110.png           основная текстура (1024×1024)
│   ├── germany_waffentrager_e110_track.png     текстура гусениц (256×256)
│   ├── germany_waffentrager_e110_light.png     текстура фар и «люстры» (256×256)
│   ├── germany_waffentrager_e110_icon.png      иконка в ангаре (789×312)
│   └── *.import                                служебные файлы Godot
├── tanks_mod/               ← копируется в assets/data/tanks_mod/ игры
│   └── germany_waffentrager_e110.tres   описание танка
└── tools/                   ← скрипты, которыми собран мод
    ├── make_glb.py
    ├── make_textures.py
    └── make_imports.py
```

## Установка

1. Скопировать `assets/tanks/germany_waffentrager_e110.*` в папку `assets/tanks/`
   игры (`.import` в игру копировать не нужно — движок импортирует ресурсы сам).
2. Скопировать `tanks_mod/germany_waffentrager_e110.tres` в
   `assets/data/tanks_mod/` игры.
3. Перезапустить игру, танк появится в ангаре под именем
   **Waffenträger E 110**.

## Характеристики

Ближайший игровой аналог в Blitz — коллекционная ПТ X уровня **Waffen F1.0**
(та же рубка Waffenträger auf E 100 на шасси E 100). Часть значений взята из
неё, часть — из карточки танка в источнике; всё редактируется в `.tres`.

| Параметр | Значение |
|---|---|
| Прочность | 1900 HP |
| Броня корпуса | 80/50/20 мм |
| Броня рубки | 20/10/8 мм |
| Масса | 83 т |
| Двигатель | Maybach HL 234WM, 1455 л.с. |
| Скорость | 38 / −12 км/ч |
| Поворот башни | 15°/с (0,2618 рад/с) |
| Орудие | 12,8 cm Kw.K. 44 L/55 WM, перезарядка 8 с, точность 0,37, прицеливание 2,55 с, 50 снарядов |
| Снаряды | AP 340/280 мм/890 м/с, APCR 300/360 мм/1240 м/с (премиум), HE 400/65 мм/790 м/с |
| Углы | −8°/+14°, обзор 240 м |

## Что сделано с моделью

Исходный `tank2/Waffentrager_E110.glb` — плоский экспорт: 11 узлов с одинаковым
поворотом +90° вокруг X, без иерархии «корпус → рубка → орудие», а гусеницы и
катки лежат кусками в общих мешах. Движок Blitz ожидает конкретную структуру,
поэтому `tools/make_glb.py` пересобирает модель:

* запекает поворот +90° в вершины (Y-вверх, −Z вперёд — как в остальных модах);
* разбирает меши шасси на **8 опорных катков на борт** (поиск связных компонент,
  критерий — круглый диск диаметром ≈0,96 м, касающийся земли) и остаток корпуса;
* склеивает траки и зубчатые венцы (`segment1_*` + `segment2*`) в одну гусеницу
  на борт;
* переименовывает узлы и собирает дерево, которое ожидает игра:

  ```
  germany_waffentrager_e110
  ├── germany_waffentrager_e110_hull_phys        бокс физики корпуса        (не рисуется)
  ├── germany_waffentrager_e110_module_tracks_40 бокс физики гусениц        (не рисуется)
  ├── hull_vis                                   корпус → chassisL/R, wheelL1…8, wheelR1…8
  ├── trackL / trackR                            гусеницы
  └── turret01                                   рубка (пивот — центр кольца)
      ├── gun01 → gun01_shoot_pos                орудие и метка дула        (метка не рисуется)
      ├── germany_waffentrager_e110_gun_mask_250 коллизия орудия            (не рисуется)
      └── germany_waffentrager_e110_armor_turret_*   броневые плиты рубки   (не рисуются)
  germany_waffentrager_e110_armor_hull_*         броневые плиты корпуса     (не рисуются)
  ```

* запекает пивоты в вершины: рубка вращается вокруг центра кольца
  (≈ `x 0,00 / z 1,64`), орудие качается вокруг цапфы (≈ `y 2,58 / z 0,22`);
* переносит меш `Turret_01` **целиком** — в нём два примитива: сама рубка и
  тонкая геометрия «люстры»/фар с материалом `tank_light_01`. Если взять только
  первый примитив (как делает наивный конвертер), фонари и провода над рубкой
  молча исчезают;
* генерирует боксы физики, метку дула и броневые плиты (80/50/20 мм корпус,
  20/10/8 мм рубка) — без них пробитие и рикошеты считаются неправильно.

### Важно: служебные узлы не должны иметь материал

Движок Blitz не рисует узлы, в имени которых есть `phys`, `armor_`, `_mask_`
или `shoot_pos` — он использует их для физики, брони и логики выстрела. Поэтому
все такие меши в моде **без материала**, ровно как в остальных модах этого
репозитория. Если дать им материал, движок начнёт рисовать поверх корпуса серые
полупрозрачные плиты.

Модель нарисована в метрах (корпус 4,30 × 8,52 м, высота по люстру ≈5 м),
поэтому в `.import` стоит `nodes/root_scale = 1.0`, а не привычные `0.1`.
Если танк окажется великоват или мелковат, поправьте `nodes/root_scale` в
`assets/tanks/germany_waffentrager_e110.glb.import`.

## Что сделано с текстурами

В `tank2/Waffentrager_E110.glb` текстуры **не вшиты** (в файле нет ни одного
изображения), поэтому проверить ориентацию по встроенным копиям, как это
делалось для 60TP, нельзя. Проверка сделана иначе: UV-островок с надписью
«ACHTUNG» на кожухе орудия спроецирован обратно на модель и отрендерен в том
виде, в каком его увидит движок.

Результат: **текстуры из `tank2/` используются как есть, без переворота по V.**
Надпись читается слева направо и не вверх ногами. У 60TP было наоборот
(текстуры Direct3D, их пришлось переворачивать) — здесь этого делать нельзя,
иначе камуфляж и все надписи встанут вверх ногами.

`tools/make_textures.py` поэтому только переименовывает файлы и приводит их к
нужному цветовому режиму (RGBA для иконки и травы гусениц), ничего не
переворачивая.

## Настройка

Всё редактируется в `tanks_mod/germany_waffentrager_e110.tres`:

| Поле | Значение | Комментарий |
|---|---|---|
| `nation` | 2 | подтверждено: 1 СССР, 2 Германия, 6 Франция (по файлам игры); остальные номера не проверены |
| `tank_class` | 3 | 0 лёгкий, 1 средний, 2 тяжёлый, 3 ПТ |
| `tree_branch` | 2 | номер ветки в дереве нации |
| `prem` | true | `false` — если танк должен быть обычным в дереве |
| `turret_rot_speed` | 0.2618 | **в радианах в секунду** (0,2618 рад/с = 15°/с) |
| `name` | germany_waffentrager_e110 | внутренний id танка |
| `matchmaker_chance` | 100.0 | шанс попасть в случайный бой |

`turret_rot_speed` задаётся в радианах в секунду, а не в градусах: если вписать
сюда 15, башня будет крутиться в 57 раз быстрее, чем нужно.

## Пересборка

```bash
python3 mods/germany_waffentrager_e110/tools/make_glb.py       # модель из tank2/Waffentrager_E110.glb
python3 mods/germany_waffentrager_e110/tools/make_textures.py  # текстуры (нужен Pillow)
python3 mods/germany_waffentrager_e110/tools/make_imports.py   # .import-файлы Godot
```

`make_glb.py` и `make_textures.py` можно запускать в любом порядке,
`make_imports.py` — после них (он проверяет, что все файлы на месте).
