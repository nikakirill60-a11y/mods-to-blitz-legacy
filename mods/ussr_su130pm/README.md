# СУ-130ПМ (SU-130PM) — мод для World of Tanks Blitz (legacy)

Пятый танк из исходников репозитория: премиумная ПТ-САУ VIII уровня СССР.
Собран из файлов папки [`tank5/`](../../tank5) по тому же принципу, что и
первые четыре мода ветки `arena/6bca88e5-mods-to-blitz-legacy`.

![Готовый мод](preview.png)

## Текстура: родная развёртка

Модель в `tank5/CU-130PM.glb` — это экспорт из Blender (glTF I/O 5.1), в котором
**сохранена оригинальная UV-развёртка** и два материала:

| Материал в исходнике | Что покрывает |
|---|---|
| `SU_130PM_mtr` | корпус, рубка, орудие, ходовая |
| `SU_130PM_track_mtr` | обе гусеницы |

Поэтому оригинальный атлас `tank5/R159_SU_130PM.dx11.dds` (2048×2048)
используется **как есть, один к одному**: `tools/make_textures.py` только
переворачивает его по вертикали и пересохраняет в PNG.

Зачем переворот: файлы игры (`tank1/`…`tank5/`) хранятся в ориентации Direct3D,
где ось V смотрит вниз, а UV в glTF/OpenGL — вверх. Если отдать файл как есть,
все люки, швы и надписи окажутся перевёрнутыми и «размазанными». Проверка:
base-color картинки, вшитые в исходные `MS-11.glb` и `60TP.glb`, **попиксельно
равны V-перевёрнутым** файлам из `tank4/` и `tank1/`, а UV моделей адресуют
именно эти вшитые картинки. По той же причине переворачивают текстуры
`mods/ussr_ms11` и `mods/poland_60tp`.

Отдельного атласа гусениц в `tank5/` нет (в игре он лежал в другом файле,
который к модели не приложен), поэтому `ussr_su130pm_track.png` **256×512**
нарисована заново: 8 траков на повтор, шов по границе тайла, U — поперёк ленты,
V — вдоль неё. Развёртка гусениц в модели как раз ленточная: один повтор V —
примерно 1.25 м ленты, отсюда шаг трака ≈ 0.16 м, как у настоящей машины.
Тайл вытянут вдвое по V специально: лента шириной 0.41 м при квадратном тайле
растягивала бы каждый трак.

Иконки конвертируются из `ussr-R159_SU_130PM@2x.packed.webp` и
`ussr-R159_SU_130PM@22x.packed.webp` (большая и маленькая).

## Модель

| Узел | Что это |
|---|---|
| `hull_vis` | корпус |
| `wheelL1…11` / `wheelR1…11` | 11 колёс на борт: ленивец, 6 опорных катков, 3 поддерживающих ролика, ведущее колесо |
| `trackL` / `trackR` | гусеницы |
| `turret01` | открытая рубка, ось вращения в центре погона `(−0.002; 1.118; 0.412)` |
| `gun01` | 130 мм М-65С, ось качания у казённика `(−0.001; 1.976; 0.299)` |
| `gun01_shoot_pos` | дульный срез, `z = −5.744` |
| `ussr_su130pm_hull_phys` / `_module_tracks_40` | невидимые коробки столкновений |
| `ussr_su130pm_gun_mask_20` | невидимая коробка орудия |
| `ussr_su130pm_armor_hull_30` / `_25` | бронеплиты корпуса, мм |
| `ussr_su130pm_armor_turret_15` / `_6` | бронеплиты рубки, мм |

Особенности исходника, которые учтены:

* Вся машина в исходнике развёрнута на 180° вокруг вертикали: ствол смотрит в
  **+Z**, тогда как у всех остальных танков репозитория (60TP, MS-11, ЛВ-1300 и
  четырёх эталонных модов) он смотрит в −Z. Поворот запекается в вершины и
  нормали (`flipped()` в `make_glb.py`), UV при этом не меняются.
* Все 7 мешей были плоскими соседями без иерархии. Погон найден по двум тонким
  плитам пола рубки; цапфы орудия — по оси длинного ствола и центру казённика.
  Как кросс-че сверены с `HP_turretJoint` / `HP_gunJoint` декомпилированной
  WoT PC модели (см. источники ниже).
* Катки каждого борта слиты в один меш, вершины разрезаны по рёбрам. Скрипт
  сваривает позиции, group-ит куски по силуэту сбоку и ставит узел каждого
  колеса в центр **всей его геометрии** — иначе pivot оказался бы на одной из
  половинок диска.
* Треугольники исходника сохранены все: 6113 видимых треугольника на входе и
  на выходе, UV-развёртка авторская и не пересчитывается.
* Узлы столкновений и бронеплит не имеют UV и материалов и не рисуются. Материалы
  glTF игрой не читаются (текстуры берутся из `.tres`), они оставлены только
  чтобы отделить корпус от гусениц.

## Характеристики

Подтверждённые данные WoT Blitz (VIII ур., ПТ-САУ, СССР, премиум):

| Параметр | Значение |
|---|---|
| Прочность | 1100 |
| Масса | 23.78 т (`hull_weight = 23780`) |
| Скорость | 50 / 20 км/ч |
| Двигатель | 512 л. с., пожар 12 % (название `В-2-СУ` условное) |
| Поворот башни | 26.73 °/с → `turret_rot_speed = 0.466526509058` рад/с |
| Поворот корпуса | 43.74 °/с на твёрдом грунте (`rot_speed = 44`) |
| Орудие | 130 мм М-65С |
| Снаряды | ББ 460 / 245 мм / 1030 м/с; КС 390 / 318 мм / 1030 м/с; ОФ 600 / 65 мм / 930 м/с |
| Перезарядка | 10.36 с (≈ 2665 урона в минуту) |
| Разброс / сведение | 0.308 м / 1.45 с |
| Углы наводки | +16° / −7° (`deviation_up = Vector2(16, 7)`) |
| Сектор обстрела | 70° / 70° (`deviation_r = Vector2(70, 70)`) |
| Боекомплект | 30 |
| Броня | корпус 30 / 25 / 20, рубка 15 / 6 / 6 мм |

Имена снарядов (`БР-482С`, `БК-482С`, `ОФ-482С`) и двигателя — условные,
удобные для `.tres`; урон, пробитие, скорость и калибр взяты из справочников.
`nation = 1` (СССР) и `tank_class = 3` (ПТ-САУ) подтверждены эталонными
модами репозитория.

## Установка

Скачайте `ussr_su130pm_install.zip` из корня репозитория и распакуйте
**содержимое** в корневую папку игры (туда, где лежит `assets/`):

```
assets/tanks/ussr_su130pm.glb
assets/tanks/ussr_su130pm.png
assets/tanks/ussr_su130pm_track.png
assets/tanks/ussr_su130pm_icon.png
assets/tanks/ussr_su130pm_icon_small.png
assets/data/tanks_mod/ussr_su130pm.tres
README.txt
```

Файлы `.import` в игру копировать не нужно — движок создаёт их сам.

## Пересборка

```bash
python3 -m pip install pillow   # или создайте venv

python3 mods/ussr_su130pm/tools/make_glb.py
python3 mods/ussr_su130pm/tools/make_textures.py
python3 mods/ussr_su130pm/tools/make_imports.py
python3 mods/ussr_su130pm/tools/make_tres.py
python3 mods/ussr_su130pm/tools/make_preview.py
python3 mods/ussr_su130pm/tools/make_zip.py
```

Все скрипты детерминированы: повторный запуск даёт побайтно те же файлы.
`make_preview.py` — чисто визуальная проверка UV и иерархии, в игру не ставится.
