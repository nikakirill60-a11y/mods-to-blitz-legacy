СУ-130ПМ (SU-130PM) - мод для World of Tanks Blitz (legacy)
===========================================================

Архив уже разложен так, как нужно игре: распакуйте его СОДЕРЖИМОЕ
в корневую папку игры (туда, где находится папка assets/) и
подтвердите объединение папок.

  assets/tanks/ussr_su130pm.glb             модель танка
  assets/tanks/ussr_su130pm.png             основная текстура
  assets/tanks/ussr_su130pm_track.png       текстура гусениц
  assets/tanks/ussr_su130pm_icon.png        иконка в ангаре
  assets/tanks/ussr_su130pm_icon_small.png  маленькая иконка
  assets/data/tanks_mod/ussr_su130pm.tres   описание танка

Файлы .import не нужны: движок создаёт их сам при первом запуске.

После запуска игры танк появится в ангаре под именем "СУ-130ПМ"
(VIII уровень, СССР, ПТ-САУ, премиумный).

ХАРАКТЕРИСТИКИ (WoT Blitz)
  1100 HP, 50 / 20 км/ч, масса 23.78 т, двигатель 512 л.с.
  130 мм М-65С: 460 / 390 / 600 урона, 245 / 318 / 65 мм бронепробития
  перезарядка 10.36 с, разброс 0.308, сведение 1.45 с, боекомплект 30
  углы наводки +16 / -7 град., сектор обстрела 70 / 70 град.
  поворот башни 26.73 град/с (0.466526509058 рад/с в .tres)

ОСОБЕННОСТИ ТЕКСТУРЫ
  В модели tank5/CU-130PM.glb сохранена родная UV-развёртка, поэтому
  основной атлас R159_SU_130PM.dx11.dds используется один к одному.
  Скрипт сборки только переворачивает его по вертикали: файлы игры
  хранятся в ориентации Direct3D, где ось V смотрит вниз, а UV в glTF -
  вверх.
  Отдельного атласа гусениц в tank5/ нет, поэтому текстура траков
  нарисована заново: 8 траков на повтор, шов по границе тайла.

НАСТРОЙКА (по желанию) - файл assets/data/tanks_mod/ussr_su130pm.tres:
  nation              нация: 1 СССР, 2 Германия, 6 Франция
  tank_class          класс: 3 ПТ-САУ
  turret_rot_speed    В РАДИАНАХ в секунду (26.73 град/с = 0.4665265)
  prem                true = премиумный танк
  health, speed_limits, guns / engines / tracks - характеристики

Подробное описание, исходники и скрипты пересборки -
в README.md папки mods/ussr_su130pm репозитория.
