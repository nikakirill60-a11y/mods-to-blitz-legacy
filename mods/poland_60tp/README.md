# 60TP Lewandowskiego — мод для World of Tanks Blitz

Польский тяжёлый танк X уровня (европейская нация) из assets/ папки `tank1/`,
оформленный по образцу остальных модов этого репозитория.

```
mods/poland_60tp/
├── assets/tanks/            ← копируется в assets/tanks/ игры
│   ├── poland_60tp.glb            модель (17,5 МБ)
│   ├── poland_60tp.png            основная текстура (2048×2048)
│   ├── poland_60tp_track.png      текстура гусениц (512×512)
│   ├── poland_60tp_icon.png       иконка в ангаре (320×200)
│   └── *.import                   служебные файлы Godot
├── tanks_mod/               ← копируется в assets/data/tanks_mod/ игры
│   └── poland_60tp.tres     описание танка (характеристики, орудие, двигатель, гусеницы)
└── tools/                   ← скрипты, которыми собран мод
    ├── make_glb.py
    ├── make_textures.py
    └── make_imports.py
```

## Установка

1. Скопировать `assets/tanks/poland_60tp.*` в папку `assets/tanks/` игры
   (`.import` в игру копировать не нужно — движок импортирует ресурсы сам).
2. Скопировать `tanks_mod/poland_60tp.tres` в `assets/data/tanks_mod/` игры.
3. Перезапустить игру, танк появится в ангаре под именем **60TP Lewandowskiego**.

## Что сделано с моделью

Исходный `tank1/60TP.glb` — плоский экспорт из Blender: у всех 28 узлов стоит
лишний поворот −90° вокруг Y, а иерархии «корпус → башня → орудие» нет. Движок
Blitz ожидает конкретную структуру, поэтому `tools/make_glb.py` пересобирает модель:

* убирает лишний поворот (данные уже Y-вверх, −Z вперёд — как в остальных модах);
* переименовывает узлы и собирает дерево, которое ожидает игра:

  ```
  poland_60tp
  ├── poland_60tp_hull_phys            бокс физики корпуса        (не рисуется)
  ├── poland_60tp_module_tracks_40     бокс физики гусениц        (не рисуется)
  ├── hull_vis                         корпус → wheelL1…11, wheelR1…11
  ├── trackL / trackR                  гусеницы
  └── turret01                         башня (пивот — turret ring)
      ├── gun01 → gun01_shoot_pos       орудие и метка дула        (метка не рисуется)
      ├── poland_60tp_gun_mantlet       маска орудия — ВИДИМАЯ
      ├── poland_60tp_gun_mask_250      коллизия орудия            (не рисуется)
      └── poland_60tp_armor_turret_*   броневые плиты башни       (не рисуются)
  poland_60tp_armor_hull_*             броневые плиты корпуса     (не рисуются)
  ```

* запекает пивоты (кольцо башни и ось орудия) в вершины, чтобы башня вращалась
  вокруг своей оси, а орудие поднималось вокруг оси качания;
* генерирует боксы физики, метку дула и броневые плиты (120/100/90 мм корпус,
  280/160/100 мм башня) — без них пробитие и рикошеты считаются неправильно.

### Важно: служебные узлы не должны иметь материал

Движок Blitz не рисует узлы, в имени которых есть `phys`, `armor_`, `_mask_`
или `shoot_pos` — он использует их для физики, брони и логики выстрела. Поэтому
все такие меши в моде **без материала**, ровно как в остальных модах этого
репозитория. Если дать им материал (например, полупрозрачный), движок начнёт
рисовать поверх корпуса серые полупрозрачные плиты — камуфляж будет выглядеть
«сломанным».

Обратная сторона того же правила: видимая маска орудия из исходной модели
раньше называлась `poland_60tp_gun_mask_250` и из-за этого **не отображалась** —
ствол выглядел обрезанным, между орудием и башней была дыра. Теперь маска
называется `poland_60tp_gun_mantlet` и рисуется, а под именем
`poland_60tp_gun_mask_250` лежит отдельный невидимый бокс коллизии орудия.

Модель нарисована в метрах (корпус 7,88 × 4,14 м, гусеницы 7,23 м), поэтому в
`.import` стоит `nodes/root_scale = 1.0` вместо привычных `0.1`. Если танк
окажется великоват или мелковат, поправьте `nodes/root_scale` в
`assets/tanks/poland_60tp.glb.import`.

## Что сделано с текстурами

Файлы из `tank1/` выгружены из игровых данных в **ориентации Direct3D**: ось V
у них перевёрнута относительно glTF/OpenGL, в которой заданы UV внутри
`60TP.glb`. Если положить их в мод как есть, камуфляж, надписи и расшивка
оказываются перевёрнутыми, а детали корпуса «переезжают» на башню — текстура
выглядит наложенной неправильно.

Проверка: базовые текстуры, вшитые внутрь `tank1/60TP.glb`, **побайтово равны**
файлам из `tank1/`, перевёрнутым по вертикали, и не равны им в исходном виде.
Именно поэтому `tools/make_textures.py` переворачивает текстуры при копировании
— после этого они совпадают со встроенными в glTF.

Ещё одна мелочь: файл иконки `60TP_Lewandowskiego_In-Game_Icon.png` на самом
деле был WebP с расширением `.png`, скрипт пересохраняет его в настоящий PNG.

## Настройка

Всё редактируется в `tanks_mod/poland_60tp.tres`:

| Поле | Значение | Комментарий |
|---|---|---|
| `nation` | 9 | подтверждено: 1 СССР, 2 Германия, 6 Франция (по файлам игры). 9 — предположительно Европа, не проверено |
| `tank_class` | 2 | 0 лёгкий, 1 средний, 2 тяжёлый, 3 ПТ |
| `tree_branch` | 2 | номер ветки в дереве нации |
| `prem` | true | `false` — если танк должен быть обычным в дереве, а не премиумным |
| `turret_rot_speed` | 0.3095 | **в радианах в секунду** (0,3095 рад/с = 17,73°/с) |
| `name` | poland_60tp | внутренний id танка |
| `matchmaker_chance` | 100.0 | шанс попасть в случайный бой |

## Пересборка

```bash
python3 mods/poland_60tp/tools/make_glb.py       # модель из tank1/60TP.glb
python3 mods/poland_60tp/tools/make_textures.py  # текстуры (нужен Pillow)
python3 mods/poland_60tp/tools/make_imports.py   # .import-файлы Godot
```

`make_textures.py` переворачивает текстуры по вертикали (см. раздел выше) и
конвертирует иконку из WebP в PNG. Первые два скрипта можно запускать в любом
порядке, `make_imports.py` — после них.
