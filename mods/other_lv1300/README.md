# ЛВ-1300 Уран (LV-1300 Uranus) — мод для World of Tanks Blitz (legacy)

Тяжёлый танк X уровня Сборной нации из серии «Ледяные Великаны» (в клиенте
игры — `Oth46_LV1300`, теги `heavyTank fictional`). Модель собрана из файлов
папки [`tank3/`](../../tank3).

## ⚠️ Текстура: важное ограничение

В исходной модели `tank3/lv1300.glb` **нет UV-развёртки** (и материалов): у всех
7 мешей есть только позиции вершин и нормали. Модель была выгружена из клиента
плагином для Blender, и координаты текстуры при этом потерялись. Поэтому
оригинальный атлас `Oth46_LV1300.dx11.png` наложить нельзя: в файле нет
информации о том, какой пиксель атласа относится к какому треугольнику. Если
попытаться наложить его «как-нибудь», получится каша.

Что сделано вместо этого:

* `tools/make_glb.py` генерирует **новую UV-развёртку**. Каждый треугольник
  проецируется вдоль главной оси своей нормали (box projection) в свою область
  текстуры, с постоянным масштабом. Нет растяжений и нет повторов через шов.
* `tools/make_textures.py` рисует под эту развёртку **новую текстуру 2048×2048**:
  окрашенная голубая броня корпуса и башни, тёмный металл орудия, тёмная сталь
  катков. Цвета взяты из оригинального атласа: медиана голой голубой плиты
  (99, 125, 140) и тёмных стальных деталей. Поверхность «потёртая»: мягкие
  пятна, зерно, царапины, подтёки.
* Отдельно нарисована текстура трака гусеницы (256×256).

В итоге танк в игре выглядит цельно и в «родной» голубой гамме, но **без
надписей, люков и мелких деталей атласа**. Если появится версия модели с UV
(например, другой плагин или исходник `.sc2/.scg`), её достаточно положить в
`tank3/` и перезапустить скрипты. Тогда можно будет наложить оригинальный
атлас один в один.

Раскладка текстуры `other_lv1300.png`:

```
+-----------+-----------+   u 0.0–0.5             корпус   (голубая броня)
|           |  башня    |   u 0.5–1.0, v 0.0–0.5   башня    (голубая броня)
|  корпус   +-----------+   u 0.5–1.0, v 0.5–0.75  орудие   (оружейный металл)
|           |  орудие   |   u 0.5–1.0, v 0.75–1.0  катки    (тёмная сталь)
|           +-----------+
|           |  катки    |
+-----------+-----------+
```

Гусеницы: U — поперёк ленты (0…1), V — вдоль ленты, один повтор текстуры на
трак (89 траков на 15,94 м ленты), как у остальных моделей репозитория.

## Модель

| Узел | Что это |
|---|---|
| `hull_vis` | корпус (4043 треугольника) |
| `turret01` | башня, ось вращения в центре погона (0; 1,978; 0,651), диаметр погона 2,54 м |
| `gun01` | орудие, ось качания у казённика (0; 2,527; −1,407) |
| `gun01_shoot_pos` | точка выстрела, дульный тормоз (z = −6,855) |
| `trackL` / `trackR` | гусеницы |
| `wheelL1…10` / `wheelR1…10` | на борт: ведущее колесо, 6 опорных катков, 2 поддерживающих ролика, ленивец |
| `other_lv1300_hull_phys` | коробка столкновений корпуса (не рисуется) |
| `other_lv1300_module_tracks_40` | коробка ходовой (не рисуется) |
| `other_lv1300_gun_mask_250` | коробка столкновений орудия (не рисуется) |
| `other_lv1300_armor_hull_200` / `_60` | лоб / борта корпуса, мм (не рисуются) |
| `other_lv1300_armor_turret_400` / `_90` | лоб / борта башни, мм (не рисуются) |

Особенности исходника, которые учтены:

* Катки каждого борта слиты в один меш (`wheel_L` / `wheel_R`), а треугольники
  не связаны между собой (вершины разрезаны по каждому острому ребру).
  Скрипт сначала сваривает вершины по позиции, потом собирает куски в колёса
  по их контуру сбоку. Зубья ведущего колеса торчат на ~5 см за диск и
  приписываются ему. В сумме 736 треугольников на борт, ровно как в исходнике.
* Узел каждого колеса стоит **в центре колеса**, вершины отсчитываются от него,
  как в оригинальных моделях `_279` и Maus. Так колесо вращается вокруг своей оси.
* В меше башни есть тонкая мачта антенны, уходящая внутрь корпуса до y = 0,61.
  Поэтому погон ищется не по самой нижней точке, а по широким деталям основания.
* Левая и правая бортовые плиты лежат в одном узле (`…_60`, `…_90`): толщина
  читается из имени узла, а два узла с одинаковым именем Godot переименовал бы
  при импорте.
* Видимая геометрия проверена: все треугольники исходника на месте, мировые
  координаты вершин совпадают с исходником.

## Характеристики

Подтверждённые данные: X уровень, тяжёлый танк, Сборная нация
(`item_defs/vehicles/other/list.xml` клиента, цена 6 100 000 серебра),
**прочность 2400**, **двигатель 1000 л. с.** (после ребаланса 12.4),
**склонение орудия −6°**. Плюс характер машины: «каменный» лоб башни, картонные
борта и крыша, «не самое мощное орудие».

Точных ТТХ орудия, скорости и брони в открытых источниках нет. Ниже —
**оценочные** значения, подобранные под описание танка (их легко поменять в `.tres`).

|---|---|---|

не описывается. Щиты не моделировались.

## Установка

Скачайте `other_lv1300_install.zip` (лежит в корне репозитория и приложен к
PR) и распакуйте **содержимое** в корневую папку игры (туда, где лежит `assets/`):

```
assets/tanks/other_lv1300.glb
assets/tanks/other_lv1300.png
assets/tanks/other_lv1300_track.png
assets/tanks/other_lv1300_icon.png
assets/data/tanks_mod/other_lv1300.tres
```

Файлы `.import` не нужны: движок создаёт их сам.

## Пересборка

```
python3 mods/other_lv1300/tools/make_glb.py       # модель + UV
python3 mods/other_lv1300/tools/make_textures.py  # текстуры (нужен Pillow)
python3 mods/other_lv1300/tools/make_imports.py   # .import
```

Все скрипты детерминированы: повторный запуск даёт побайтно те же файлы.
