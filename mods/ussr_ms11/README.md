# МС-11 — мод для World of Tanks Blitz (legacy)

Коллекционный средний танк X уровня СССР с **барабаном на 11 снарядов**
(награда новогоднего события 2025/26, обновление 12.6, в клиенте Lesta —
`30209-11`). Модель собрана из файлов папки [`tank4/`](../../tank4).

## ⚠️ Барабан: экспериментальная часть

Барабан описывается в `.tres`. Как именно движок хранит магазин, нигде не
документировано. Что известно точно, по модам из папки `mods/`:

* у каждого орудия есть подресурс `burst_info` (скрипт
  `res://assets/data/tank_info/burst_info.gd`), но во всех примерах он **пустой**;
* единственный пример заполненного `cycle_info` (`reload`, `intrashot`,
  `volley_charge_time`) и `fire_mode = 3` — двуствольный Mäuschen
  (`germany_mauses`). Там цикл из двух выстрелов, по одному на каждый ствол
  (`gun01_shoot_posL` / `gun01_shoot_posR`).

Поэтому сделано так:

* время задано именами, известными из `cycle_info`: `reload = 22.05` (перезарядка
  барабана) и `intrashot = 0.8` (между выстрелами);
* **число снарядов (11) записано сразу под всеми правдоподобными именами**
  (`count`, `shots`, `shell_count`, `clip_size`, `size`, …) и в `burst_info`, и в
  `cycle_info`. Godot не падает на незнакомых полях ресурса: лишние он просто
  игнорирует, а подходящее подхватит;
* значение `fire_mode` для магазина неизвестно. Основной файл использует
  `fire_mode = 2` (по логике перечисления: 1 — очередь, 2 — цикл, 3 — цикл +
  залп у Mäuschen). Остальные значения лежат в `variants/`.

| Файл | Что внутри |
|---|---|
| `tanks_mod/ussr_ms11.tres` | **основной**: барабан, `fire_mode = 2` |
| `variants/fire_mode_1/ussr_ms11.tres` | барабан, `fire_mode = 1` |
| `variants/fire_mode_3/ussr_ms11.tres` | барабан, `fire_mode = 3` (режим Mäuschen) |
| `variants/no_drum/ussr_ms11.tres` | **без барабана**, перезарядка 2,73 с — тот же урон в минуту (3075) |

Все варианты отличаются только описанием орудия: модель, текстуры и остальные
ТТХ одинаковые. Чтобы попробовать другой вариант, положите его файл вместо
`assets/data/tanks_mod/ussr_ms11.tres` и перезапустите игру. Если ни один
барабанный вариант не заработает (или игра на нём не запустится), `no_drum`
даёт ту же огневую мощь обычным орудием.

Что проверить в игре:
1. стреляет ли танк 11 раз подряд с паузой ~0,8 с;
2. уходит ли он после 11-го выстрела на перезарядку ~22 с;
3. не высаживается ли весь барабан одним нажатием (это признак «очереди»).

## Модель

| Узел | Что это |
|---|---|
| `hull_vis` | корпус с кормовым «ковшом» (3013 треугольников) |
| `turret01` | башня вместе с маской орудия, ось вращения в центре погона (0; 1,731; −0,099) |
| `gun01` | ствол, ось качания у его заднего торца в маске (0; 2,095; −1,401) |
| `gun01_shoot_pos` | точка выстрела, дульный тормоз (z = −4,618) |
| `trackL` / `trackR` | гусеницы (исходная развёртка) |
| `wheelL1…9` / `wheelR1…9` | на борт: ведущее колесо, 4 опорных катка, 3 поддерживающих ролика, ленивец |
| `ussr_ms11_hull_phys` | коробка столкновений корпуса (не рисуется) |
| `ussr_ms11_module_tracks_40` | коробка ходовой (не рисуется) |
| `ussr_ms11_gun_mask_250` | коробка столкновений маски орудия (не рисуется) |
| `ussr_ms11_armor_hull_120` / `_70` / `_60` / `_200` | лоб / борта / корма / «ковш» корпуса, мм |
| `ussr_ms11_armor_turret_200` / `_90` / `_60` | лоб / борта / корма башни, мм |

Особенности исходника, которые учтены:

* **Ориентация.** На каждом узле был лишний поворот −90° по вертикали. Сами
  вершины уже лежат правильно (Y вверх, ствол в −Z), как у 60TP, поэтому
  поворот просто убран. Проверено рендером.
* **Текстура.** Исходная развёртка сохранена. Картинки, вшитые в glb, — это
  попиксельно перевёрнутые по вертикали файлы `*.dx11*.png` из `tank4/`
  (проверено поканально, разница 0). Поэтому в мод идут перевёрнутые файлы. По
  этому же правилу исправлялась текстура 60TP.
* **Маска орудия** входит в меш башни (в исходнике меш называется
  `1_gun_01_mask_nc`). Она остаётся видимой частью `turret01`. Слово `mask` есть
  только у невидимой коробки `…_gun_mask_250`, поэтому движок не спрячет
  видимую деталь. Ствол качается вокруг своего заднего торца, который сидит в
  отверстии маски (z −1,401 против −1,410), поэтому на +15° / −10° зазора не
  появляется.
* **Ходовая** каждого борта слита в один меш (`wheel_L` / `wheel_R`), а колпаки
  ступиц — отдельные куски. Скрипт сваривает вершины, разбивает меш на колёса
  и приклеивает каждый колпак к колесу, в контур которого он попадает. Узел
  колеса стоит в его центре, поэтому колесо вращается вокруг своей оси. В сумме
  628 треугольников на борт, ровно как в исходнике.
* Все 6465 видимых треугольников исходника на месте, габариты совпадают.
* Ни у одного видимого узла нет в имени `phys`, `armor_`, `mask_` или
  `shoot_pos`. Имена всех узлов уникальны.

## Установка

Скачайте `ussr_ms11_install.zip` (лежит в корне репозитория и приложен к PR)
и распакуйте **содержимое** в корневую папку игры (туда, где лежит `assets/`):

```
assets/tanks/ussr_ms11.glb
assets/tanks/ussr_ms11.png
assets/tanks/ussr_ms11_track.png
assets/tanks/ussr_ms11_icon.png
assets/data/tanks_mod/ussr_ms11.tres
variants/…                       (не обязательно: варианты барабана для проверки)
```

Файлы `.import` не нужны: движок создаёт их сам.

## Пересборка

```
python3 mods/ussr_ms11/tools/make_glb.py       # модель
python3 mods/ussr_ms11/tools/make_textures.py  # текстуры (нужен Pillow)
python3 mods/ussr_ms11/tools/make_imports.py   # .import
python3 mods/ussr_ms11/tools/make_tres.py      # .tres + варианты барабана
```

Все скрипты детерминированы: повторный запуск даёт побайтно те же файлы.
