# scgviewer — просмотр моделей WoT Blitz (`.sc2` / `.scg`)

## Как запустить (Windows)

1. Скачайте [`scgviewer.zip`](https://github.com/nikakirill60-a11y/mods-to-blitz-legacy/raw/arena/6bca88e5-mods-to-blitz-legacy/scgviewer.zip) и распакуйте в любую папку.
2. Если ещё нет Python — поставьте с [python.org](https://www.python.org/downloads/) (галочка «Add python.exe to PATH»).
3. Запуск:
   * **двойной щелчок по `SCGViewer.bat`** — откроется окно просмотрщика, перетащите в него модель или папку;
   * **перетащите на `SCGViewer.bat` файл** `Tank.sc2.dvpl` / `Tank.scg.dvpl` **или целую папку** (например
     распакованную `Data/3d/Tanks/USSR`) — окно сразу откроется с моделью, все модели папки будут в списке;
   * правый щелчок по `.sc2` / `.dvpl` → «Открыть с помощью» → `SCGViewer.bat` — дальше открывается двойным щелчком.

Окно — это Edge или Chrome в режиме приложения (без вкладок и адресной строки), программа сама закрывается
вместе с окном. Без Python `SCGViewer.bat` просто откроет `scgviewer.html` в браузере — всё тоже работает,
только файлы надо перетащить в окно вручную.

| Файл | Что это |
|---|---|
| **`SCGViewer.bat`** / `SCGViewer.pyw` | программа-просмотрщик (окно, перетаскивание файлов и папок на значок) |
| **`scgviewer.html`** | сам просмотрщик — один HTML-файл, работает и без Python, без интернета, файлы никуда не отправляются |
| **`scgtool.bat`** / `scgtool.py` | консольная утилита: сводка, дерево, материалы, экспорт в OBJ, дамп в JSON, распаковка `.dvpl` |
| `dava.py` | разбор форматов DAVA для `scgtool.py` |

## Какие файлы понимает

* **`.sc2`** — сцена DAVA (SceneFileV2): иерархия деталей, LOD, материалы, пути к текстурам.
  * новый формат (v41–v43, текущие версии игры) — геометрии внутри нет, она в парном `.scg`;
  * старый формат (v23 и около, старые моды) — геометрия прямо в `.sc2`.
* **`.scg`** — геометрия (SCPG): вершины, индексы. Без `.sc2` показывается «россыпью», без иерархии и материалов.
* **`.dvpl`** — сжатые файлы игры (`Tank.sc2.dvpl`, `Tank.scg.dvpl`, `*.dds.dvpl`). Распаковываются на лету (LZ4, CRC проверяется).
* **Текстуры**: `.dds` (DXT1/DXT3/DXT5/BC4/BC5/BC7, несжатые RGBA), `.pvr` (PVR3: несжатые, DXT, ETC1/ETC2), `.png`, `.webp`, `.jpg`.
  Путь `images/Имя.tex` из материала ищется как `Имя.dx11.dds(.dvpl)`, `.dds`, `.png`, `.dx11.pvr`.


## 3D-просмотрщик

1. Запустите `SCGViewer.bat` (или откройте `scgviewer.html`).
2. Перетащите в окно **папку** с моделью (например распакованную `Data/3d/Tanks/USSR`) — или выберите
   кнопками «Открыть файлы / папку». Достаточно `Tank.sc2` + `Tank.scg`, текстуры из `images/` подхватятся сами.
3. Если в папке несколько танков — выберите нужный в списке моделей.

Возможности:

* дерево деталей с галочками (`hull`, `turret_01`, `gun_01`, `chassis_*` …), фильтр по имени;
* щелчок по детали — подсветка и свойства: позиция, компоненты, LOD, формат вершин, материал, текстура;
* переключение **LOD** (0 — самый подробный, «все» — все сразу);
* **Служебные** — точки крепления `HP_*`, объёмы теней, «crash»-версии (по умолчанию скрыты, как в игре);
* текстуры вкл/выкл, каркас, сетка, отсечение задних граней; гусеницы рисуются с прозрачностью (alphatest);
* виды «Спереди / Сбоку / Сверху / 3/4», мышь: левая — вращать, правая/Shift — сдвигать, колесо — зум,
  двойной щелчок — центрировать на детали; клавиши **F** (показать всё), **W** (каркас), **T** (текстуры);
* **экспорт**: GLB (видимые детали с иерархией и текстурами — для Blender / Godot, оси переводятся в Y-вверх),
  OBJ, JSON (сырые данные файла), снимок PNG.

## scgtool.py

```
python scgtool.py                          открыть 3D-просмотрщик
python scgtool.py info   Tank.sc2.dvpl     версии, LOD, треугольники, какие текстуры найдены, габариты
python scgtool.py tree   Tank.sc2          дерево узлов: батчи, LOD, материалы, служебные детали
python scgtool.py mats   Tank.sc2          материалы, шейдеры (fx), текстуры, родительские материалы
python scgtool.py obj    Tank.sc2 -o tank.obj [--lod 0|all] [--service]
python scgtool.py json   Tank.sc2 -o tank.json [--scg] [--full]
python scgtool.py unpack Data/3d/Tanks -o unpacked      распаковать все .dvpl, сохраняя папки
```

Перетащить файл на `scgtool.bat` = команда `info`.

## Как устроены файлы (кратко)

* **DVPL**: данные + 20 байт в конце — `u32 размер_распак., u32 размер_сжат., u32 crc32, u32 тип (0 — без сжатия, 1/2 — LZ4), "DVPL"`.
* **SCG**: `"SCPG", u32 версия, u32 кол-во, u32 кол-во2`, далее KeyedArchive на каждую полигон-группу
  (`#id`, `vertexFormat`, `vertexCount`, `vertices`, `indexFormat` 0=u16/1=u32, `indexCount`, `indices`, `rhi_primitiveType`).
* **Формат вершин** — битовая маска, атрибуты идут подряд: 0 позиция, 1 нормаль, 2 цвет, 3–6 UV0–3, 7 тангент, 8 бинормаль, 14/15 кости.
* **SC2**: `"SFV2", версия, кол-во узлов`, теги версий, описание, затем `#dataNodes` (материалы, у старых — и геометрия)
  и `#hierarchy` (детали). Деталь: `TransformComponent` (локальная/мировая TRS), `RenderComponent` → батчи
  (`rb.datasource` = id полигон-группы, `rb.nmatname` = id материала, `lodIndex`, −1 = во всех LOD).
* Оси DAVA: **Z вверх, +Y — вперёд** (куда смотрит пушка); треугольники против часовой (как в glTF).

## Проверка

```
node   tests/test_core.js  [свои файлы .sc2 …]     ядро просмотрщика (src/core.js)
python tests/test_dava.py                         парсер dava.py и экспорт OBJ
python tests/make_fixture.py                      пересоздать тестовую модель tests/fixtures/demo_tank.*
python build.py                                   собрать scgviewer.html из src/
```

Проверено на настоящих моделях из модов (`.sc2` v23 с геометрией внутри: ELC AMX, Maus, Hetzer, SU-100Y),
на настоящем `T-34-85.sc2.dvpl` v43 (иерархия, материалы, трансформации), и на синтетической модели нового
формата `tests/fixtures/demo_tank` (SC2 v43 + SCG v1 в `.dvpl`, LOD, служебные детали, alphatest,
наследование материалов, индексы u16 и u32). Публичного настоящего `.scg` из текущей версии игры найти не
удалось — формат `.scg` сделан по исходникам DAVA и открытым парсерам (BlitzKit, WotbTools); если ваш
файл откроется с ошибкой — пришлите его, поправлю.

GLB-экспорт проверен официальным валидатором Khronos glTF-Validator: 0 ошибок, 0 предупреждений.
