# Поля `.tres` танка — что известно

Справка собрана по эталонным модам из `mods/` и по файлам самой игры: AMX 50 100,
AMX 50 B и Leichttraktor. Игру перенесли с Godot на Unity, но танки по-прежнему
описываются файлами `.tres` в формате Godot, и игра на Unity читает их своим кодом.
Поэтому `script = ExtResource("…/burst_info.gd")` здесь только метка типа ресурса,
а набор поддерживаемых полей определяет код игры (C#). «Подтверждено» значит, что поле встречается в файлах игры или в эталонных
модах. Смысл некоторых полей выведен по значениям и помечен как предположение.

## Нации (`nation`)

| Значение | Нация | Откуда известно |
|---|---|---|
| 1 | СССР | эталонный мод «Объект 279» |
| 2 | Германия | эталонные моды Maus, Tashenratte, Sturmtiger |
| 6 | Франция | AMX 50 100 и AMX 50 B из файлов игры |
| 8, 9 | Сборная / Европа? | **не проверено** (используются в модах ЛВ-1300 и 60TP) |

Порядок не совпадает ни с WoT, ни с Blitz (там Франция была бы 5). Чтобы узнать
остальные номера, нужен `.tres` любого танка США, Великобритании, Китая или
Японии из игры.

## Классы (`tank_class`)

0 — лёгкий (у Leichttraktor поле не записано, то есть стоит значение по умолчанию; предположение),
1 — средний (предположение), 2 — тяжёлый (Maus, AMX 50 100, AMX 50 B), 3 — ПТ-САУ (Sturmtiger).

Редактор Godot **не записывает поля со значением по умолчанию**. Поэтому у Leichttraktor нет
`lvl` (I уровень), `tank_class`, `caliber`/`shot_sound` у второго орудия и `power` у
двигателя. Если поля нет в файле, это не ошибка.

## Барабан / магазин — формат подтверждён

Пример из игры: Leichttraktor, орудие 2 cm Breda (магазин 12 снарядов, очереди по 3).

```
[sub_resource type="Resource" id="Resource_1fd5q"]
script = ExtResource("3_clcyb")          ; burst_info.gd
bursts = Array[int]([3, 3, 3, 3])
intraclip = 0.25
intraburst = 0.25

; в орудии (module_gun.gd):
reload = 6.5                             ; перезарядка всего магазина
fire_mode = 1
burst_info = SubResource("Resource_1fd5q")
```

| Поле | Смысл |
|---|---|
| `bursts` | список «очередей» в магазине: элемент — одно нажатие, число — сколько выстрелов в нём. Сумма = ёмкость магазина |
| `intraclip` | пауза между очередями внутри магазина, с |
| `intraburst` | пауза между выстрелами внутри одной очереди, с |
| `fire_mode = 1` | орудие стреляет по `burst_info` (магазин) |
| `reload` | у магазинного орудия — перезарядка всего магазина |

Барабан, который стреляет по одному снаряду (как в Blitz), — это очереди по 1:

```
bursts = Array[int]([1, 1, 1, 1])        ; барабан на 4
intraclip = 2.73                         ; между выстрелами
intraburst = 2.73
fire_mode = 1
reload = 25.3
```

Так сделан МС-11 (`mods/ussr_ms11`): 11 × 1, `intraclip = 0.8`, `reload = 22.05`.

Другие механики:
* `cycle_info` (`reload`, `intrashot`, `volley_charge_time`) + `fire_mode = 3` — двуствольный
  Mäuschen: поочерёдные выстрелы из двух стволов и залп.
* Пустой `burst_info` без `fire_mode` — обычное однозарядное орудие. Так в файлах
  игры описаны и AMX 50 100, и AMX 50 B, то есть в этой версии игры они без
  барабана, хотя `reload` у них барабанный (18–29 с).
* У топовых танков (AMX 50 B) поля `unlock_tanks` нет, а двигатель и ходовая
  указаны дважды одинаковыми (сток = топ). Наши моды указывают по одному модулю,
  и это работает.
